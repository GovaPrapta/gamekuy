Siaga Karhutla Nusantara

Musim kemarau ekstrem (El Nino) melanda. Titik api bermunculan akibat cuaca kering dan ulah oknum penebang serta pembakar lahan ilegal. Pimpin Satgas Nasional, kerahkan Manggala Agni, helikopter water bombing, dan tangkap para oknum demi langit Nusantara yang biru!

Target: 5 hari berturut-turut tanpa satu pun titik api (1 hari = 20 detik). Waspadai skandal korupsi, uang tutup mulut, preman tanah, dan cuaca ekstrem. Api yang dibiarkan lama menggerus reputasi, dan reputasi di bawah 20% = Satgas dibubarkan.
